# Qué documenta este sitio

GresstDocs es **documentación de producto** (cómo se usa Gresst, casos de negocio). No es el manual de desarrollo.

| En este sitio | No en este sitio (código) |
|---------------|---------------------------|
| Guías de usuario, [casos de entrada/salida](casos_entrada_salida_residuos.md), [arquitectura para operación](arquitectura.md), [soporte / Jira](procesos_operativos.md) | Contratos GraphQL/REST, cómo clonar y desplegar, ADRs, design system, capture UX |

El mapa técnico de repos: **[API/docs/SOLUTION.md](https://github.com/Gresst/GresstAPI/blob/main/docs/SOLUTION.md)** (código de la API). Quien clona hermanos en disco usa `../API/docs/SOLUTION.md`.
